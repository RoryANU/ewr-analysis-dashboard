Add your own scenario

Runs the EWR tool (py_ewr) on your model output. Choose the format of your file, using the EWR tool's own format names. The file is scanned for every gauge in this review, so a file can cover more than one SDL unit. The scenario then appears in the Scenario / Base / Comparison pickers (Historical only).
